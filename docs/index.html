미국 주식 팩터 랭킹 대시보드

무료 데이터 기반 백테스트 결과를 GitHub Pages에서 보기 좋게 확인하는 정적 대시보드입니다. 팩터별 성과·위험 지표, 최신 편입 종목과 비중, 데이터 한계를 한 화면에서 비교합니다.

중요: 이 페이지는 연구용 정적 스냅샷입니다. 표시된 결과는 투자 조언이나 매매 지시가 아니며, 우주(universe), 리밸런싱, 필터, 무료 데이터 품질, 랭킹 공식에 따라 달라집니다.
