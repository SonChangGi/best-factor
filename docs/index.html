Update automation

수동 업데이트 실행 화면 열기 워크플로 상태 보기
  • 07:00 KST Tue-Sat 직전 미국 정규장 기준 live-data run.
  • 09/11/13 KST fallback JSON stale/missing/broken일 때만 재실행.
  • 검토 후 수동 재실행 workflow_dispatch로 동일 경로 실행.

저장소 권한 필요 · 실행 완료 후 이 페이지의 생성 시각과 데이터 기준일을 확인하세요.

공개 JSON의 generated_at과 data_end_date를 기준으로 최신성 게이트를 판단합니다.

CLI 실행 예시 gh workflow run update-dashboard.yml --repo SonChangGi/best-factor --ref main
리서치 고지: 연구용 정적 스냅샷입니다. 투자 조언이나 매매 지시가 아니며, 다중검정·데이터 품질·필터 조건에 따라 결론은 달라질 수 있습니다.
