미국 주식 팩터 랭킹 대시보드

무료 데이터 기반 미국 개별주식 factor-zoo 백테스트 결과를 정적 대시보드로 제공합니다. 팩터별 성과·위험 지표, 최신 편입 종목과 비중, 데이터 품질 게이트를 표와 차트로 함께 확인하세요.

중요: 이 페이지는 연구용 정적 스냅샷입니다. 표시된 결과는 투자 조언이나 매매 지시가 아니며, “최고 팩터”는 수백 개 테스트 후보 중 이번 실행에서 1위라는 뜻입니다. 최근 tail holdout 보조 검증을 함께 표시하지만 완전한 out-of-sample 검정은 아니므로 우주(universe), 리밸런싱, 필터, 무료 데이터 품질, 랭킹 공식, 다중검정/데이터 스누핑 위험에 따라 결론은 달라집니다.

Update automation

자동·수동 최신 데이터 갱신

Best Factor 전용 GitHub Actions가 한국 시간 기준 매일 09:00에 yfinance 무료 데이터를 새로 받고, 10:00·12:00·15:00·18:00에는 공개 JSON이 없거나 stale이면 다시 실행합니다.

수동 업데이트 실행 화면 열기 워크플로 상태 보기
  • 09:00 KST 기본 자동 업데이트
  • 10:00 KST stale/missing 데이터 감지 시 재실행
  • 12:00 KST 공급자 지연·일시 실패 대비 2차 확인
  • 15:00 KST 무료 데이터 지연 대비 같은 날 재시도
  • 18:00 KST 최종 같은 날 stale 데이터 확인

저장소 권한 필요 · 실행 완료 후 이 페이지의 생성 시각과 데이터 기준일을 확인하세요.

공개 JSON의 generated_at과 data_end_date를 기준으로 최신성 게이트를 판단합니다.

CLI 실행 예시 gh workflow run update-dashboard.yml --repo SonChangGi/best-factor --ref main

Portfolio

최신 편입 종목과 투자 비중

테스트 후보 중 최고 팩터에 해당하는 최신 롱온리 연구용 모형 포트폴리오입니다. 비중은 close-to-close 백테스트 산출물이며 실제 주문 가능 수량, 세금, 비용, 슬리피지는 반영하지 않습니다.

대시보드 설명

  • 종합 점수는 여러 성과/위험 지표를 표준화해 합산한 비교용 점수입니다.
  • 최고 팩터는 현재 정렬 기준이 아니라 백테스트 산출물의 종합 점수 기준 1위이며, 수백 개 테스트 후보 중 1위라는 의미입니다.
  • 비중은 해당 팩터의 최신 리밸런싱 스냅샷이며, 실제 체결 가능성은 별도 점검이 필요합니다.
  • 업데이트 버튼은 브라우저에서 계산하지 않고 GitHub Actions 수동 실행 화면을 엽니다.
